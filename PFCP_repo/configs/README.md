# Configuration

Store deployment-specific Open5GS/UERANSIM and NWDAF settings here.

Do not commit credentials, private keys, production addresses, or other sensitive deployment information.

Recommended files:

- `detection.yaml` — thresholds and monitoring intervals
- `open5gs-notes.md` — version and non-default configuration notes
- `topology.example.yaml` — sanitized testbed addressing example
